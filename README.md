### About

I'm a software engineer and founder of **RichMo DevStudio** — where I build custom mobile apps, web systems and IoT solutions, from the first sketch to the published product.

Before founding the studio, I spent **15+ years as an R&D engineer** in hardware and firmware for the energy and industrial sectors: metering, automation and protection of electric power distribution systems. That product-engineering background is what lets me deliver software today with the same discipline — performance, reliability and code the client actually owns.

Currently pursuing an **MBA in Software Engineering at USP/Esalq**, while keeping technical R&D work at HartBR through RichMo and expanding the studio to new clients and markets.
